# Prehistoric visual assets

The creature art in this directory is original prototype artwork created for PrehistoricTux.

Current prototype set:
- small green ground hunter (raptor)
- ancient snake (snake)
- flying prehistoric hunter (ptero)

These are deliberately low-resolution, clean silhouettes for gameplay testing. They are not the final UHD presentation assets. Final production art will preserve the same animation/action names so level files do not need to be rewritten when artwork is upgraded.
